# Security Policy

## Supported versions

Only the latest release receives security fixes. Releases are listed on the
[releases page](https://github.com/roalcantara/lida/releases) and in [CHANGELOG.md](CHANGELOG.md).

## Reporting a vulnerability

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/roalcantara/lida/security/advisories/new). Please do not open a
public issue. Include the lida version (`lida --version`), the command you ran, and a minimal `TODO.md` or `TODO.yaml`
that reproduces it.

You get an acknowledgement within a week. A fix ships as a patch release, and the advisory is published with it.
