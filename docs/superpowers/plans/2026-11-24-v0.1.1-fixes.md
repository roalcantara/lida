# lida v0.1.1 Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix every known lida bug in one patch release (v0.1.1) so the latest v0.1.x is "stable": no data loss, no
wrong results, output and docs that match.

**Architecture:** Fixes land in `lida-core` (parsers, store, formats) and `lida` (commands, output, CLI declaration),
one task per reviewable fix group, each test-first. Output changes update their insta snapshots and DESIGN.md in the
same commit. No new features: every commit is `fix`/`docs`/`test`/`ci`/`build`/`chore`/`ref`.

**Tech Stack:** Rust 1.100 workspace, usage-rs 7.4 (CLI, completion, spec), serde + serde_yaml_ng, owo-colors, insta.

**Spec:** [docs/superpowers/specs/2026-11-24-v0.1.1-fixes-design.md](../specs/2026-11-24-v0.1.1-fixes-design.md)
(its numbered items 1–22 are cited below as "spec N"). Audit with repros: `/private/tmp/lida-audit-2026-11-24.md`
(cited as "audit #N").

## How to run this plan

- Run it with `/wip:run plan=docs/superpowers/plans/2026-11-24-v0.1.1-fixes.md`; finish with `/wip:handoff`. The
  plan's author reviews with `/wip:review`.
- Branch `fix/v0.1.1` (exists; `git switch fix/v0.1.1 && git pull`). Never push to `main`, never merge, never tag.
  Push the branch only at the end (Task 12), then open the PR; the owner merges.
- One task = one commit unless a step says otherwise. Each commit closes its TODO.md tasks with lida
  (`cargo run -q -p lida -- done <id>`, ID found by description in `cargo run -q -p lida -- list -t v0.1.1 --json`)
  and stages `TODO.md` with it.
- Stop and ask the owner instead of guessing when: a test can only pass by loosening a lint, threshold or check; a
  snapshot changes in a task that does not say it should; a real-file fixture (Task 4) does not round-trip and the
  fix would change the file format beyond this plan.
- After an interrupted turn, re-read `git status` and the last commit before continuing.

## Global Constraints

- Commit types: `fix`, `docs`, `test`, `ci`, `build`, `chore`, `ref` only (a `feat` would make this v0.2.0).
- Never start a commit-body line with "breaking change" (any case): the changelog reads it as a breaking change.
- Conventional Commits, sentence-case subject ≤ 72 chars; `git add <paths>` then `git commit`; never `-a`.
- Error copy: every message starts lower-case; `main` prefixes `error: `; exit 1. Argument (parse) errors stay exit 2.
- `--json` output keeps its exact shape (keys and `null`s). Only TODO.yaml drops empty keys.
- `lida-core` must not depend on usage-rs, owo-colors or lida (`core-purity`). No new dependency in `lida-core`.
- No crate- or module-wide `allow`; scoped `#[expect(…, reason = "…")]` only. jscpd threshold 0 holds.
- Snapshots: `INSTA_UPDATE=no cargo nextest run --workspace` must pass at every commit. Re-record only in a task
  that says its output changes (`INSTA_UPDATE=always cargo nextest run -p lida`), then open every changed `.snap`
  and confirm each diff is exactly the intended change.
- Gate per task: `mise run gate --fast`; full `mise run gate` and `mise run audit` before Task 12's push.

## Review Focus

1. **v0.1.0 files keep loading:** a `TODO.md` without the new `**Comments**` field line, written by v0.1.0, loads with
   empty links and saves without loss (Task 4, `old_md_without_comment_links_round_trips`).
2. **CRLF `TODO.md`:** a file saved with `\r\n` line endings is recognised line by line, not refused as unknown
   (Task 4, `crlf_markdown_is_recognised`).
3. **`cwi` to the current format is a no-op:** `cwi md` in Markdown mode deletes nothing (Task 3,
   `cwi_to_current_format_deletes_nothing`).
4. **Snapshot churn hides regressions:** Task 8 strips ANSI from every snapshot at once; the reviewer must see that
   removing the escape codes from each old snapshot yields the new one (Task 8 Step 5).
5. **Dual-write from Markdown:** `cwi both` from `md` creates `TODO.yaml` and keeps `TODO.md` (Task 3,
   `cwi_both_keeps_both_files`).
